# Challenge 02 — Safety Instrumented Bypass

**Points:** 250 · **Difficulty:** Hard · **Surface:** TriStation-lite (TCP 1502) · **Toolkit:** `sysrupt tristation`

> Spoiler-free. This guide explains the *surface* and the *idea* — not the answer.

## The Story

A **Safety Instrumented System (SIS)** is the last line of defence in a plant — it trips the process to a
safe state when something goes wrong. In the 2017 TRITON/TRISIS attack, intruders targeted a Triconex
safety controller to disable exactly that protection. Here you face a simplified safety controller
("TriStation-lite"): defeat its write-lock *without* breaking the checksum it validates, and hold the
trip disabled.

## Where to start

- The safety controller listens on **TCP 1502**.
- Explore it read-only first: `./bin/sysrupt help tristation` (read / dump / watch).
- A direct write to the protected variable is **rejected** — that's expected.

## Objectives

1. Confirm a direct write is blocked.
2. Open the short-lived **program lock** window.
3. Read the rolling key the controller expects.
4. Disable the trip — and hold it disabled.

## Hints

<details><summary>1. The write is rejected. Now what?</summary>

Safety controllers gate programming behind a lock. Look for how the lock is opened and how long it stays
open — the window is short. `watch`/`dump` help you see state change over time.
</details>

<details><summary>2. What is the "rolling key"?</summary>

The controller expects a value that changes — a verification token that must accompany a privileged
write. Read it fresh; a stale one won't validate.
</details>

<details><summary>3. Why does my disable keep reverting?</summary>

Disabling isn't a one-shot — the challenge wants the trip held in the disabled state. Think about doing
the privileged write *inside* the open window and keeping the condition satisfied.
</details>

## What you'll learn

- How safety controllers protect privileged writes (lock windows + rolling keys).
- Why checksum validation alone is not security.
- The real-world stakes of SIS compromise (TRITON/TRISIS).

## Scoreboard

Awarded when the safety trip is disabled and held.
