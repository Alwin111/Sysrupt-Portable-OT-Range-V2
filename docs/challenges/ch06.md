# Challenge 06 — Second Blackout

**Points:** 300 · **Difficulty:** Expert · **Surface:** GOOSE training stream (UDP 6180) · **Toolkit:** `sysrupt goose`

> Spoiler-free. This guide explains the *surface* and the *idea* — not the answer.
> Note: this is a **GOOSE-shaped exercise over UDP 6180**, not raw Layer-2 Ethernet multicast — so you
> work with it over the badge network, not a span port.

## The Story

**GOOSE** (IEC 61850) carries fast protection messages between substation devices — and it is
unauthenticated. The 2016 Industroyer malware abused substation protocols to black out part of Kyiv. A
bay relay here trusts a GOOSE publisher completely. Watch the normal stream, then forge a state change
it will accept.

## Where to start

- The GOOSE bay publishes on **UDP 6180**.
- The toolkit does it all: `./bin/sysrupt help goose` — **sniff**, **decode**, **send**, **sustain**.
- Confirm the breaker's believed position on the intranet: `http://10.0.1.1/intranet` (the bay GOOSE
  subscriber's accepted state and last `stNum`).

## Objectives

1. Observe the normal GOOSE stream.
2. Learn its identifiers (APPID, confRev, the current state number).
3. Forge the **next** state number with the breaker-open flag set.
4. Send it so the subscriber accepts the trip.

## Hints

<details><summary>1. What do I need before I can forge a frame?</summary>

Sniff first (`goose sniff`). A subscriber only accepts a frame that carries the right APPID and confRev
and a state number it considers *newer* than the last one it saw.
</details>

<details><summary>2. Why is my forged frame ignored?</summary>

State numbers must move forward. If your `stNum` isn't greater than the one the subscriber last accepted,
it's treated as stale. Decode the latest frame to read the current value, then go one higher.
</details>

<details><summary>3. It flips then flips back — how do I hold it?</summary>

The publisher keeps asserting the real state. `goose sustain` re-sends your state for a bounded time so
the forged value stays accepted. Watch the intranet breaker panel to confirm.
</details>

## What you'll learn

- How GOOSE publish/subscribe and state numbers work.
- Why unauthenticated protection messaging is dangerous.
- How to sniff, decode, forge and sustain a protocol event.

## Scoreboard

Awarded when the subscriber accepts the forged breaker-open state.
